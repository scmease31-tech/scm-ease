How the links work: change Module Wattage, FX Rate, Modules to Build or MW Output at the top and every row — consumption, landed cost, $/W, containers, total value — recalculates instantly. Editing MW Output directly back-solves Modules to Build (and vice versa) — they're the same number two ways. Freight logic: each material has its own Container Qty — Freight $/unit = Freight $/Container ÷ Container Qty. Leave the override columns blank to inherit the global default; type a number to override that one material only. Every grey cell is a live formula — double-click it to give that one row a custom formula, or open the ƒ(x) Formulas tab to edit the formula for an entire column at once, add new columns, or remove custom ones.
This is the formula engine behind every grey cell. Each row below is one column of the table. Formulas are plain JavaScript expressions — reference any other column by its key (shown in the second column) and the five global inputs as G.wattage, G.fx, G.freight, G.localfreight, G.nummodules. Edit a formula and the whole column recalculates immediately for every row. Tick "include in TOTAL row" to have that column summed at the bottom of the table. Columns you add yourself can be removed; the built-in columns can't (but their formulas are fully editable).
